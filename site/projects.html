STIG Dashboard

An offline, risk-ranked viewer for DISA STIG checklist results, in a single HTML file.

Built with assistance from Claude Code.

  • Private by design. Runs in your browser. Nothing is uploaded.
  • Bring your checklists. Drop in many .ckl and .cklb files at once.
  • Ranks by risk, not raw counts. Exposure scores weighted by severity.
  • Matches your scanner. Criticality override via CSV to match ACAS.
  • Five views. Dashboard, Assets, STIGs, Findings, Compliance.
  • Mapped to RMF. Findings roll up to control families.
  • Drill all the way down. From environment to host to the exact rule.

PokéMans

A Pokémon card and species collection tracker with daily price history.

Built with assistance from Claude Code.

independance

A visual dependency map for projects, tasks and POA&Ms.

Built with assistance from Claude Code.

  • Auto-arranging layout. Tiles group and arrange by dependency chain.
  • Chain highlighting. Select a tile to spotlight its full chain.
  • Rich in-place editing. Expand a tile to edit it, POA&M fields included.
  • Fast linking. Drag tile onto tile to link, or hover to quick-add.
  • Rollups and filters. Downstream counts on projects, filter any field.
  • Customizable. Your own fields, types, statuses, light/dark.
  • Fully local. No account, no cloud. Local SQLite file.
